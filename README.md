# 港序 20 分钟路演：产品视频版

[在线演示](https://shuaimxu.github.io/gangxu-roadshow/)

离线入口为 `index.html`。解压整个目录后双击打开，保持 `media/` 与 HTML 相邻，可离线使用。左右方向键翻页，F 全屏；视频点击播放，可单独全屏。

- 13 页主讲、4 页附录。
- 讲解与页内录屏 14 分钟，现场演示 4 分钟，缓冲 2 分钟，总预算 20 分钟。
- `路演主讲稿.md`：逐页口播、承接句、演示步骤和答辩口径。
- `讲稿与演示安排.md`：控时表及附录用法。

沿用原深蓝与亮蓝配色，增加港序 Logo、成员照片及角色定位。核心产品页使用录屏与业务说明并置。素材来自原仓库及用户提供《港序_20分钟路演_含视频.pptx》。
