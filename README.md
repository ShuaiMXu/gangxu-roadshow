# 港序 · 决赛路演

20 分钟路演整合版 v1：12 页主讲、4 页附录。

- 讲解 14 分钟，现场演示 4 分钟，缓冲 2 分钟。
- 业务中枢组织多角色协作，结合智能大脑、3D 方案、人机切换与经验复盘。
- 数据区分业务现状、录制案例和历史合成评测，不代表生产收益。

## 下载成品

在 [v1.0 版本下载页](https://github.com/ShuaiMXu/gangxu-roadshow/releases/tag/v1.0) 下载可编辑 PPT 或完整 HTML 演示包。

PPT 已内嵌 5 段录屏，13–16 页为隐藏附录。请在路演电脑上确认 PowerPoint 的视频播放效果。

## HTML 演示

下载仓库或完整演示包后，保持 `media/` 与 HTML 文件相邻。双击 `index.html`，方向键翻页，F 键全屏，点击视频播放。

此仓库为私有素材仓库，未发布公开网站。

## 内容

- `index.html`：演示页面。
- `media/`：产品截图、视频海报与录屏。
- `讲稿与演示安排.md`：逐页计时、讲稿提示和现场备选方案。

现场演示尚未完成真实业务环境全流程彩排。表格输入需要按支持的合同核对字段、单位并由人确认。
