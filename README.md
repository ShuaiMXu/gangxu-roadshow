# 港序 20 分钟路演：产品视频版

[在线演示](https://shuaimxu.github.io/gangxu-roadshow/)

离线入口为 `index.html`。解压整个目录后双击打开，保持 `media/` 与 HTML 相邻，可离线使用。手机左右滑动或点底部按钮翻页，电脑左右方向键翻页，F 全屏；视频点击播放，可单独全屏。

- 16 页主讲、4 页附录。
- 讲解与页内录屏 14 分钟，现场演示 4 分钟，缓冲 2 分钟，总预算 20 分钟。
- `路演主讲稿.md`：逐页口播、承接句、演示步骤和答辩口径。
- `讲稿与演示安排.md`：控时表及附录用法。

主讲部分按订单核对、派车、装载和签收展开，随后说明两项模拟测试和配送规则复盘。附录含测试范围及备用录屏。

## 现场使用

下载 [PowerPoint 视频版](gangxu-roadshow.pptx)，在桌面 PowerPoint 中进入放映模式，点击视频画面播放。视频与逐页演讲者备注均内嵌在文件中。
